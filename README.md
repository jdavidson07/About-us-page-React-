**Key Features & Improvements:**
- Rewrote static HTML/CSS into React components for longterm maintainability.
- Implemented interactive features including an accordion, a live chat widget, and a community milestone tracker.
- Built a site-wide search feature using React Context, allowing users to locate and auto-scroll to relevant content.
- Clean, modern, and accessible layout designed for seamless navigation across desktop and mobile devices.

I created this project to have hands on experience using React - a JavaScript library to build user interfaces using components for front end development. 


**Stack:**
- React — component architecture, hooks, Context API
- Vite — build tool and dev server
- JavaScript 
- HTML5 / CSS3 — Flexbox, Grid, animations, media queries
- Git / GitHub — version control

To run this project, follow these steps: 

**Clone the repository:**
```bash
git clone https://github.com/jdavidson07/About-us-page-React-.git
cd About-us-page-React-
```

**Install Dependencies** 
```bash
  npm install
```

**Run the server**
```bash
  npm run dev
```


**What I learned** 
- Gained a practical understanding of React fundamentals, including component composition, state management with `useState`,`useEffect`,`useRef` and conditional rendering of dynamic UI.
- Learned to build and apply custom React Hooks such as the Intersection Observer API for scroll-trigger animations.
- Learned how to convert static HTML elements into reuseable React components for use across projects.
- Developed a workflow for using browser DevTools to diagnose bugs and solve rendering issues.
